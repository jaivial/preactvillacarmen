# GEO / LLM discovery

The public site publishes `https://www.alqueriavillacarmen.com/llms.txt` with canonical HTML links and one Markdown alternative for every public content route, in Spanish and English. This includes the public booking-start page, which remains noindex and outside the HTML sitemap; token-based booking-management and private administration routes have no Markdown alternative. Markdown URLs use `/index.md` below the HTML route (for example `/arroces-y-paellas/index.md`); they are not included in the HTML sitemap and are not shown in the UI. Each HTML head advertises its alternative with `link rel="alternate" type="text/markdown"`.

`robots.txt` links to `https://www.alqueriavillacarmen.com/sitemap.xml` and explicitly allows the listed search/AI crawlers. Backoffice and downloads remain excluded. Markdown responses carry `X-Robots-Tag: noindex, follow` and a YAML canonical pointing to the HTML page, so they supplement rather than compete with HTML indexing. There is deliberately no `llms-full.txt`: the per-page documents are the single full-content source and avoid a second stale aggregate.

The prerender build reads the same public restaurant API used by SSR and writes the HTML, sitemap, robots and Markdown together. The two rice editorial routes contain explicit active-menu markers. On origin requests, `publicMarkdownHandler` refreshes only that marked section from restaurant 1 menus 41 (day), 42 (weekend) and 1 (rice), reusing the tested shared dish renderer. It includes weekend rice only when menu 42 is active/public, deduplicates dishes and retains backlinks to each active relevant menu. The HTML rice SSR and Markdown refresh use a one-minute in-memory cache with five-minute stale-while-revalidate; the last good document is served if the API is temporarily unavailable. Static Markdown is served from the build output with the same noindex header. Menu `lastmod` values are refreshed from their API `modified_at` values for the live rice documents and their sitemap entries; a full build refreshes all routes.

No hidden CSS text or cloaking is used. JSON-LD remains sourced from the existing restaurant/content configuration. NAP is intentionally unchanged pending confirmation of the definitive address and the Thursday/Sunday opening hours.

Submit this exact sitemap in Search Console after deployment: **https://www.alqueriavillacarmen.com/sitemap.xml**.
